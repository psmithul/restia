# Restia v3.1

Restia v3.1 is a slightly-major security release. It replaces the former
"authenticated browser equals unlocked device" assumption with a real
server-verified WebAuthn boundary.

## Shipped

- Passkey enrollment for platform authenticators and security keys, protected
  by current-password and active-TOTP step-up.
- Exact origin and relying-party validation, required user presence and user
  verification, signature-counter validation, encrypted single-session
  challenges, and bounded credential payloads.
- Short-lived device-unlock grants attached to one database-backed session.
  API tokens and ordinary cookies never satisfy the unlock policy.
- Account-owned passkey listing and password/MFA-protected revocation. Password
  rotation and passkey revocation clear existing unlock grants.
- Settings UI for registration, device verification, and revocation, plus an
  honest account security-posture report.
- Alembic revision `20260731_0016`, SQLite/PostgreSQL schema validation, and
  real P-256 WebAuthn registration/assertion tests.
